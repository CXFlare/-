# M-07：分析脚本组织与复用

## 组织原则
按阶段而不是按家族：

```
scripts/
├── 01_triage/           # 分流
├── 02_unpack/           # 脱壳
├── 03_static/           # 静态
├── 04_ioc/              # IOC 提取
├── 05_report/           # 报告
└── 99_custom/           # 一次性
```

## 命名
- `<阶段>_<动作>.py`
- 一次性脚本用 `_` 前缀
- 通用脚本不加下划线

## 可提炼的通用脚本
- _extract_all_iocs.py（IOC）
- _hash_all.py（哈希）
- _gen_yara_full.py（YARA）
- _gen_sigma_full.py（Sigma）
- _gen_stix.py（STIX）
- _gen_misp.py（MISP）

## 常见坑
1. 不要过度抽象
2. 参数化（输入输出路径用命令行传）
3. 单个文件失败不阻塞批量

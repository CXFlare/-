# M-03：.NET 双阶段加载器分析方法

## 触发条件
样本是 .NET 程序集，反编译后看到 Assembly.Load / Activator.CreateInstance。

## 步骤

### 1. 反编译外层
```
disrobe dotnet decompile <sample> --out <outdir>
```
读 native.cs：
- 找 InitializeComponent / Main
- 提取 XOR key 字节数组
- 提取资源名（如 ZH）

### 2. 定位隐藏资源
- 找 `GetObject("name")` 的字符串参数
- 或找资源魔数 `0xBEEFCACE`

### 3. 手工解密
```python
def decrypt(original, key):
    n = len(original)
    out = bytearray(n)
    orig = bytes(original)
    for i in range(n):
        a = orig[i]
        b = orig[(i+1) % n]
        k = key[i % len(key)]
        out[i] = ((a ^ k) - b + 256) & 0xFF
    return bytes(out)
```

### 4. 扫描并提取 PE
- 遍历 PE 所有位置
- 每次取 4KB~256KB，解密后检查 MZ + PE 签名
- 找到后按 PE 节表计算完整大小

### 5. 脱壳内层
- 内层通常是 SmartAssembly / ConfuserEx
- 用 disrobe dotnet deobfuscate

## 本次实例：AgentTesla
- 外层伪装 Panda Cafe（.NET 4）
- 22 字节 key：548BHE35Z8SH7888GSBYD9
- 内层 payload 67072 字节
- 内层保护：SmartAssembly 7.3.0.3296

## 常见坑
1. key 是 List<byte>.Add() 逐字节写
2. 向后引用 (i+1) % n
3. 资源名混淆（'ZH' / 'A' / 单字符）
4. 内层仍被保护：SmartAssembly 需专门工具

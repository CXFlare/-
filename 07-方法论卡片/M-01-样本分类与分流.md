# M-01：恶意软件样本分类与分流

## 触发条件
拿到一批新样本（zip 包、家族目录、散落文件），需要快速分类并决定分析路径。

## 步骤

### 1. 批量哈希 + 大小
```
for f in samples/*:
    md5 = hashlib.md5(data)
    sha256 = hashlib.sha256(data)
    size = os.path.getsize(f)
```
输出：ALL_SAMPLES_HASHES.csv

### 2. 编译器/壳识别
```
disrobe identify <sample>
```
关注输出：format / compiler / packer / installer

### 3. 按编译器/壳分流
| 编译器/壳 | 深挖路径 |
|---|---|
| MSVC 原生 | disrobe behavior + disasm |
| .NET | disrobe dotnet decompile |
| Delphi | IDA + 专用签名 |
| AutoIt EA06 | 需 myAut2Exe（暂时跳过）|
| NSIS | 7z 或 disrobe extract |
| UPX | upx -d |
| VMProtect | 需 obpo / d810-ng（暂跳过）|
| MEW | 需专用脱壳（暂跳过）|
| pkr_ce1a | 需专用脱壳（暂跳过）|
| ELF | readelf + strings |

### 4. 提取 IOC
统一脚本跑：URL / IP / .onion / TG Bot / Discord Webhook / BTC / XMR / 注册表键

## 常见坑
1. 证书 URL 噪音：CRL / OCSP / sectigo / digicert 类要过滤
2. 中文路径问题：Python 在某些编码下无法打开中文路径，用纯英文 work 目录
3. Defender 拦截：样本运行时文件被锁定，读不到内容，需要排除目录
4. AV 自动删除：把 Defender 实时保护关掉或加排除

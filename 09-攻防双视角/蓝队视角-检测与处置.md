## 处置 Playbook

### 步骤 1：隔离
- 立即断开网络（保留内存）
- 不要关机（保留磁盘 + 内存）
- 保存内存 dump 供后续分析

### 步骤 2：取证
- 抓取：%TEMP% / %APPDATA% / %LOCALAPPDATA%
- 检查：注册表 Run / RunOnce / ShellServiceObjectDelayLoad
- 检查：进程树异常父子关系
- 检查：网络连接异常外联

### 步骤 3：清除
- 删除持久化注册表键
- 删除落地文件（kk32.dll / surf.dat 等）
- 清除计划任务
- 重置受影响账号密码

### 步骤 4：恢复
- 从已知干净备份恢复
- 更新 AV / EDR 规则
- 添加 C2 到 DNS 黑名单
- 通知相关人员（可能外泄的凭据）

### 步骤 5：复盘
- 分析样本确认家族
- 追溯初始访问路径
- 更新检测规则
- 演练优化
